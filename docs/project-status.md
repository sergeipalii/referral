# Статус проекта

> **Проект ЗАМОРОЖЕН с 2026-06-23.**

## Что произошло

- Активная разработка и эксплуатация **остановлены**.
- Продакшен-сервер (Hetzner CPX22, `178.105.37.83` / `refledger.io`) **удалён**.
  Все запущенные сервисы (postgres, backend, frontend, Caddy, Adminer) больше не существуют.
- Исходный код полностью сохранён в этом git-репозитории — это единственный
  оставшийся артефакт проекта.

## Что это значит на практике

- Никакого живого окружения нет: домен, API (`/api/*`), веб-интерфейс и БД недоступны.
- Бэкапов БД (restic → Backblaze B2, см. `ops/backup/`) по факту больше нет, так как
  сервер с заданиями cron удалён. Если в B2 остались старые снапшоты — их срок
  хранения истечёт по политике retention без обновления.
- Внешние интеграции (Paddle Billing, healthchecks.io, Telegram-уведомления)
  фактически не получают трафик; их следует считать неактивными.

## Возобновление работы

Репозиторий самодостаточен. Для подъёма с нуля:

1. Поднять инфраструктуру заново (см. `docs/system-overview.md`, `CLAUDE.md`,
   `docker-compose.yml`).
2. Завести `.env` по `.env.example` (БД, `JWT_SECRET`, Paddle-ключи и т.д.).
3. Применить миграции (`npm -w @referral-system/backend run migration:run`).
4. Перенастроить внешние сервисы (Paddle, домен, бэкапы).

Историческое описание возможностей системы — в `docs/system-overview.md`
(отражает состояние на момент заморозки, актуальным окружением не подкреплено).
